# PVText

Nine roles, nothing between them. Fraunces carries `display`→`cardTitle`;
Manrope carries `body`, `bodySm`, `label`, `meta`.

```jsx
<PVText role="title2">What is happening this week</PVText>
<PVText role="body">Your baby is about the length of a banana…</PVText>
<PVText role="meta">4 min · read</PVText>
```

Large type gets negative tracking and tight leading; body copy wants the
opposite. Body never goes below 13.
