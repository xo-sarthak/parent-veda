# PVButton

Outlined pill, transparent fill. **There is no filled variant, and no `variant`
prop.** If a screen seems to want a big violet call-to-action, check instead
that the primary action is in the lower third and that the eyebrow above it is
doing its work.

```jsx
<PVButton label="Open your journal" icon={<PVIcon name="book" size={16} />} />
<PVButton label="Not now" tone="quiet" />
<PVButton label="Save this week" block />
```
