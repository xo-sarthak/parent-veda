# PVEmptyState

What a section renders when it holds nothing yet. A feature is never hidden.

```jsx
<PVEmptyState
  title="Nothing saved yet"
  body="Write the first thing you want to remember about today."
  action={<PVButton label="Start a note" />}
/>
```

Write the copy as an invitation. "No entries yet" states a fact about the
database; the line above states what she would get.
