# My Child phase paintings - one ChatGPT prompt per phase

For the redesigned "all phases" screen (`lib/screens/post_pregnancy/phase_map_screen.dart`, 2026-10-15).
Each prompt is complete on its own. Paste one, generate, and save the image as
`phase_NN` (01-20). Claude converts it to `assets/phases/phase_NN.webp` (1024 square).
House style: the onboarding paintings (`assets/onboarding/ob_a1.jpg`).
Until a painting exists, the screen shows the phase number in a disc of its colour.
