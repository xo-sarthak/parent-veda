**Build rules that still apply (from earlier incidents):**
- Before **every** release build, delete the three stale parentRelease folders under
  `build/app/intermediates/` (`merged_native_libs`, `stripped_native_libs`,
  `merged_jni_libs`, each `/<flavor>Release`). Gradle has repackaged an old `libapp.so`
  more than once.
- Run one build at a time. Overlapping builds have shipped an APK with no fonts or icons.
- Walk builds pass `--dart-define=PV_DEV=true`, or the stage switch on You disappears.
- Before installing, check the APK contains `MaterialIcons` and a string that only new
  code has.
